# Resplandy brand files

Mascot and wordmark generated with Gemini on 19 Nov 2026 and cut out by script. The original image is `resplandy-logo-original.png`.

These images are not covered by the repository's MIT licence: see the Licence section of the top-level `README.md`.

| File | Use |
| --- | --- |
| `resplandy-logo.png` | Logo with dark text, transparent background: README, slides on light backgrounds |
| `resplandy-logo-dark-bg.png` | Same logo with light text, for dark backgrounds |
| `resplandy-mascot.png` | Mascot alone, transparent background |
| `resplandy-wordmark.png`, `resplandy-wordmark-light.png` | The word alone, dark or light text |
| `favicon.ico` | Browser tab icon (16, 32 and 48 px inside) |
| `favicon-16.png`, `favicon-32.png`, `favicon-48.png` | The same icon as separate PNGs |
| `apple-touch-icon.png` | 180 px, white background, for iPhone and iPad home screens |
| `icon-192.png`, `icon-512.png` | Larger icons, transparent background |

For an HTML page:

```html
<link rel="icon" href="favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="favicon-32.png">
<link rel="apple-touch-icon" href="apple-touch-icon.png">
```
